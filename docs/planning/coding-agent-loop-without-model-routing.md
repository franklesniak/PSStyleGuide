# Parent orchestration loop without model routing

Run from the PSStyleGuide planning checkout. Use `coding-agent-loop.md` for authority, risk controls, compact state, task execution, validation, native operations, authenticated reviewer substitution, independent quality, maintenance gates, merge readiness and completion. Follow the active plan's explicit execution order and preserve completed/superseded historical IDs. Read that shared prompt and the current task before execution; this wrapper changes only routing and executor concurrency.

Use the current coding agent. Do not select, prove or record a model route, and do not run a model-routing advisor. Use one task executor at a time. Do not create a descendant unless the user or current task explicitly requires one and defines independent scope and ownership. The parent owns sequence, scope, compact state, validation, publication and completion decisions. Pass another repository's executor only its objective, scope, risk, known findings, required inputs, validation and completion condition.

Keep planning files/state on the planning branch and preserve unrelated owner work. This wrapper supplies no new authority, does not reactivate retired tasks and does not replace the shared review controller with copied rules. The post-PR212 amendment remains inactive until its actual acceptance boundary is met.
