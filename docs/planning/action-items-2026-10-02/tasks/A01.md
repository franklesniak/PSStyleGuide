## Scope

Read-only complete issue and Git-tree inventories.

## Work

Read all open issues and relevant discussion in both repositories with complete pagination. Pin native default-branch commits and trees. Enumerate the tracked-tree union, including one-sided paths, modes and renamed counterparts. Use PATH-INVENTORY.md as a dated baseline, not a fixed allowlist. Include historical required paths absent from both trees through the original requirement map.

Read [the lifecycle and convergence policy](../LOOP-POLICY.md) once. Use its source PR → review → merge → peer diff → peer repair PR → review → merge → reverse-diff loop for each actual code change. Apply [the user decision process](../DECISION-PROCESS.md) to each distinct confirmed finding. Do not create a PR for a proved no-change result. Read [parallel ownership](../ROUTING-AND-PARALLELISM.md) before assigning a writer.

## Validation

Compare Git objects, not dirty working files. Add each new issue or new path to an outcome before dispatch. A new ambiguity or security classification escalates to gpt-6.1-sol/high or gpt-6-astra/high. Confirm no open PR already owns a proposed repair.

## Complete when

Every live issue and every tracked or historically required path has one owner; current input commits and raw-byte differences are recorded. New issues cannot be skipped because they were absent from this snapshot.

Historical task completion alone does not satisfy this current predicate. A conditional no-change result must include its evidence and trigger. A blocked prerequisite cannot be replaced with a success label.

## Original requirements and restart

Original IDs owned here: New explicit live-issue obligation; see ISSUE-COVERAGE.md.

Find each original contract in [the historical map](../HISTORICAL-MAP.md), and read only the relevant files. The old bodies preserve source requirements and historical instructions; they do not override this plan's current routing, loop limits or approved dispositions. No requirement disappears merely because a mechanism is retired.

At each meaningful boundary, return the current repository/branch/head, changed paths, tests, decision/evidence links, PR round/clock, transfer count, pending operation and one next action to the coordinator. After a restart, read the tracker first, then this file and the referenced pending result. Never repeat a possibly accepted public mutation without readback.
