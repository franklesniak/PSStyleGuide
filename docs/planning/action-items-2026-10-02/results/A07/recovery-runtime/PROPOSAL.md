These use short direct controlled English. No formal ASD-STE100 dictionary certification is claimed.

Keep candidate permissions empty. Never change host Git configuration.
3. Require a reviewed PowerShell7 host before installer invocation. Do not launch this installer under 5.1. Use the acquired preferred Node in both actual Windows harness editions. 5. Download with the fixed platform curl application. Put `--disable` first. Use the fixed official HTTPS URL, HTTPS-only protocol and redirects, TLS validation, connect20, max180, retry2 and retry-max300. Preserve native transient retry selection. Do not use `--retry-all-errors`. Use a fresh owned output file. Check native status. Check the exact archive hash before listing, extraction or execution. Do not retry a digest failure. Require no pre-existing linked ancestor. Check the resulting executable paths and directories again. Do not claim ZIP extraction alone prevents parent-junction traversal. Preserve A04's trusted-runner proxy/CA assumption; this proposal does not claim a network sandbox. Do not project npm/GitHub credentials.
