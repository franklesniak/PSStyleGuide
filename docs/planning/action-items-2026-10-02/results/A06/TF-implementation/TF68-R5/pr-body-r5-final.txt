## Problem and resulting behavior

Terraform's generator, exact-path verifier and artifact gate used separate implementations from the accepted PowerShell foundation. This PR ports the common implementation from [PS234](https://github.com/franklesniak/PSStyleGuide/pull/234), accepted at `98177628b7bc02c646724bfc8aa0fd73fed0cd24`. Terraform retains its language descriptors, independent output allowlist and actual recovery semantic checks.

The generator prepares complete payloads before publication and uses the shared versioned result contracts. The artifact gate retains bounded child execution, checked native status, the first resolved Node executable and final identity checks. The build requires 156 generator assertions twice on each of Windows PowerShell 5.1, Windows PowerShell 7 and native-ext4 Linux PowerShell 7 for the same revision before artifact publication.

Two hosted runs exposed a metadata fixture defect at UTC midnight: synthetic documents kept the previous day's date while child validators read the new day. Private fixture clock controls now cover the actual current, delayed, accepted-worktree, proposed, local and capacity callers. They check exact source anchors and completed clock readbacks, preserve primary errors and remove their state after each action. The production validator and its date policy retain accepted bytes.

Further testing found that literal brackets in a checker path were interpreted as a wildcard by `Set-PSBreakpoint`. The helper now applies `WildcardPattern.Escape` only to its two breakpoint path arguments. Source reading and execution retain the original literal path. The persistent regression uses `clock-probe[fixture].ps1` and the matching decoy `clock-probef.ps1`; it requires exactly two new breakpoints, both on the intended file. Existing negative clock controls and cleanup assertions remain in place.

A fresh audit also identified [GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7) in the Markdown checker dependency graph. An exact workflow-root override selects KaTeX 0.18.2 under `micromark-extension-math@3.1.0`. This crosses the parent's declared range; installation and lint compatibility were checked explicitly. Current callers parse math syntax, and no browser rendering exploit was established here. The dependency-maintenance note records why the override is needed and when to remove it.
