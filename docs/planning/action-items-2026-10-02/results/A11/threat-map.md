AWS CLI documents automatic pagination and that `--prefix` is a prefix, so the explicit equality filter remains necessary. Directory buckets are outside this operation. [AWS list-object-versions](https://docs.aws.amazon.com/cli/latest/reference/s3api/list-object-versions.html).

Azure CLI documents `--num-results '*'` for all results, prefix matching and download overwrite default true. Explicit `--overwrite false` and exact-name filtering preserve the intended narrower action. [Azure blob CLI](https://learn.microsoft.com/en-us/cli/azure/storage/blob?view=azure-cli-latest). Azure versioning excludes hierarchical-namespace accounts and requires supported account types. [Azure versioning](https://learn.microsoft.com/en-us/azure/storage/blobs/versioning-overview).

GCS documents that no-clobber skips existing destinations and `--do-not-decompress` retains compressed object bytes. The example additionally requires a new validated local payload. [gcloud storage cp](https://docs.cloud.google.com/sdk/gcloud/reference/storage/cp). HCP's list endpoint uses organization/workspace filters and explicit page parameters; its response can carry hosted state-download URLs. [HCP state-version API](https://developer.hashicorp.com/terraform/cloud-docs/api-docs/state-versions).
